# FocusFlow

A minimalist Pomodoro timer built with React, TypeScript, and Vite.

## Features

- **Pomodoro Mode** — Configurable focus sessions with short and long breaks
- **Task Management** — Add, edit, reorder, and track tasks with time tracking
- **Configurable Tones** — 10 built-in tones (4 normal, 6 annoying) plus custom audio upload
- **Volume Control** — Adjustable volume slider for alerts
- **Browser Notifications** — Get notified even when the tab is in the background
- **Keyboard Shortcuts** — Space (start/pause), R (reset), S (skip session)

## Getting Started

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)
- Web Audio API (tone synthesis)
